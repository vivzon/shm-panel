# SHM Panel

SHM Panel is a lightweight, secure, and modern web hosting control panel designed for Ubuntu-based VPS and Dedicated servers. It provides a complete stack (Nginx, Multi-PHP, MariaDB, Postfix/Dovecot, FTP, Redis) and features a beautiful WHM (Reseller/Admin) and cPanel (Client) interface.

## 🚀 Features
- **Modern Stack:** Nginx, PHP (8.1, 8.2, 8.3), MariaDB, Redis.
- **Mail Server:** Postfix & Dovecot with Roundcube webmail integration.
- **Database Management:** Automated phpMyAdmin deployment.
- **Security First:** Built-in CSRF protection, secure PDO prepared statements, and SSH key management.
- **Automated SSL:** Let's Encrypt integration for the panel and all subdomains.
- **Performance:** Pre-configured OPCache, Nginx FastCGI caching, and system swap optimization.
- **Beautiful UI:** Built with Tailwind CSS, Lucide Icons, and ApexCharts.

## 📦 System Requirements
- **OS:** Ubuntu 20.04, 22.04 LTS, or 24.04 LTS (Fresh install required).
- **RAM:** Minimum 2GB (4GB+ recommended).
- **Disk:** Minimum 20GB.
- **Network:** A valid domain name pointing to your server's public IP address.
- **User:** Root privileges required.

## 🛠️ Installation Guide

There are two primary ways to install SHM Panel. The **Modular Installer** is recommended for most users.

### Method 1: The Modular Installer (Recommended)
This method uses a well-structured set of bash scripts to provision your server step-by-step.

1. **Log in to your server as root:**
   ```bash
   ssh root@your_server_ip
   ```

2. **Clone or upload the SHM Panel files** to your server (e.g., in `/root/shm-panel`).

3. **Make the installer executable:**
   ```bash
   cd /root/shm-panel
   chmod +x install.sh
   chmod +x installer/*.sh
   ```

4. **Run the installer:**
   ```bash
   ./install.sh
   ```
   *The installer will prompt you for your primary domain name, administrator email, and server IP address. It will automatically generate secure passwords for your database and panel admin.*

### Method 2: The Vivzon Core Installer (Alternative)
If you are deploying specifically for the `vivzon.cloud` infrastructure, you can use the monolithic script.

```bash
cd /root/shm-panel
chmod +x setup_vivzon.sh
./setup_vivzon.sh
```

## 🔒 Post-Installation Security Steps (CRITICAL)

Once the automated installation is complete, you must secure the panel by running the deployment security script. This script removes leftover installation files and locks down file permissions.

1. **Run the security cleanup script:**
   ```bash
   chmod +x deploy_security.sh
   sudo ./deploy_security.sh
   ```

2. **PHP Configuration (php.ini):**
   To further harden the server, ensure that dangerous PHP functions are disabled at the server level. Run the following command to automatically update all PHP versions:
   ```bash
   sed -i 's/^disable_functions =.*/disable_functions = system,exec,passthru,shell_exec,proc_open,popen/g' /etc/php/*/fpm/php.ini
   systemctl restart php8.1-fpm php8.2-fpm php8.3-fpm 2>/dev/null || true
   ```

## 🖥️ Accessing the Panel

After the installation and security lockdown are complete:

- **Client Panel (cPanel):** `http://your-domain.com/cpanel/`
- **Admin Panel (WHM):** `http://your-domain.com/whm/`

**Default Admin Credentials:**
Check the `/root/shm-credentials.txt` file (if generated by the modular installer) for your auto-generated passwords. If you used the standalone web/vivzon installer, the default username is usually `admin`.

> **Note:** We strongly recommend changing the admin password immediately upon first login.

## 🧰 The `shm-manage` CLI Tool

SHM Panel comes with a powerful command-line utility located at `/usr/local/bin/shm-manage` (which must be run as root or via `sudo` by the `www-data` user).

You can use it to manage services directly from the terminal:
```bash
# Add a new SSH key for a user
sudo shm-manage ssh-key add client_username "ssh-rsa AAAA..."

# Clear user logs
sudo shm-manage clear-client-logs client_username

# Check system status
sudo shm-manage status
```

## 🛡️ Security Architecture
- Database queries use strict **PDO prepared statements** to prevent SQL injection.
- Passwords are hashed using the modern **BCrypt** algorithm via `password_verify()`.
- Sessions are protected with `Secure` and `HttpOnly` cookie flags and prevent session fixation.
- Shell commands bridging the PHP web interface to the Linux system are strictly sanitized using `escapeshellarg()`.
